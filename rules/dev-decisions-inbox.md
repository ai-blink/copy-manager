# dev-decisions-inbox — copy-manager

> 아직 구현 방향이나 우선순위를 확정하지 않은 항목만 둔다. 결정되면 `rules/dev-decisions.md`로 이동한다.

## 보안 후속

- [ ] **민감 항목 미저장** — 비밀번호 관리자·일회용 코드 등 저장하면 안 되는 클립보드 내용을 식별·제외할 범위와 오탐 처리 방식.
- [ ] **외부 내비게이션 차단** — renderer의 `will-navigate`, `setWindowOpenHandler` 정책과 허용할 외부 열기 동작.

## 성능·사용성 후속

- [ ] **대용량 이미지 처리** — 현재 이미지 data URL을 JSON에 직접 저장한다. 썸네일/원본 분리, 크기 제한, 파일 저장 여부를 결정해야 한다.
- [ ] **실사용 후 기능 판단** — 드웰 가속 곡선과 트레이/백그라운드 상주는 1주 평가 결과가 있을 때만 도입한다.

해결된 캡처·저장소·핫키·붙여넣기·렌더러·리모컨·설정 결정은 D19~D32에 기록되어 있다.
