# dev-context — copy-manager

## 현재 상태 (2026-08-25)

- 브랜치 `main`, 앱 버전 `0.2.4`. S1~S11 구현 완료.
- `release\copy-manager Setup 0.2.4.exe`와 `release\win-unpacked\copy-manager.exe`를 패키징했다.
- 2026-08-15 전역 단축키 동작을 “재누름 시 숨김”에서 “창 복원·표시·활성화”로 변경했다.
- 2026-08-20 기본 비핀 히스토리를 100개로 늘리고, 1~1000 직접 입력·빠른 값 선택과 핀 보존 중복 제거를 추가했다.
- 2026-08-20 검색바에 현재 결과/최대 보유 개수를 표시하고, 설정을 왼쪽 사이드바 탭으로 분류했다.
- 2026-08-20 전역 단축키 직접 입력을 세 콤보박스 선택으로 교체했다.
- 2026-08-20 단축키 화면 표기를 `Ctrl + Alt + V`처럼 사용자 기준으로 바꾸고, 충돌한 새 키는 경고 후 기존 키를 유지하도록 했다.
- 2026-08-23 기존 카드를 복사·붙여넣기 하면 새 카드 대신 그 항목이 맨 앞으로 승격되도록 바꾸고(D34), 적재 경로도 같은 내용이면 승격하는 dedupe-on-insert 로 전환했다.
- 2026-08-23 복사 피드백을 카드 오버레이에서 창 하단 토스트로 바꾸고(3줄·900ms), 배색 4종과 불투명도·글자 크기·여백을 설정 창/표시 탭에 노출했다. 기본값은 육안 비교로 고른 보라·0.31·13px·10/18px이다.
- 2026-08-25 클립보드 캡처를 250ms로 단축하고, 전체 히스토리 저장을 350ms 디바운스·호출 순서 직렬화·임시 파일 교체로 바꿨다. 종료 전 flush, 최신 항목 자동 스크롤, 단일 인스턴스 잠금도 적용했다(D35).
- 2026-08-25 250ms 폴링만으로는 `win+v`에 기록된 빠른 중간 복사를 놓칠 수 있어 `WM_CLIPBOARDUPDATE` 이벤트 감시를 추가했다. 250ms 폴링은 안전망으로 유지하고, 200개에서 201번째가 oldest 비핀을 교체하는 경계 테스트도 추가했다(D36).
- 2026-09-20 카드가 없는 실제 본문 여백·하단 안내 띠를 창 드래그 영역으로 넓히고, 창 재활성화 시 모달·우클릭 메뉴가 없을 때 검색어를 보존한 검색창에 포커스를 복원했다(D37). 기존 `move` 이벤트의 250ms 위치 저장·재시작 복원을 재사용했다. `typecheck`·36개 테스트·build는 통과했고, 실제 GUI 확인(M44~M45)은 남아 있다.
- 최근 자동 검증은 `npm run typecheck`, `npm test`(36개), `npm run dist` 통과다. D36 설치본을 무인 교체하고 패키지/설치본 `app.asar` 해시 일치, 본체 1개·이벤트 감시 프로세스 1개 실행을 확인했다. 실제 연속 복사 GUI 검증(M43)은 남아 있다.
- dev-docs 정본은 루트 `rules/`이며 `.claude/rules/`에는 위치 안내만 둔다.

## 다음 우선순위

1. 빠른 연속 복사·최신 항목 자동 스크롤·단일 인스턴스(M42)를 개발 앱과 다음 설치본에서 확인한다.
2. 보유 개수 직접 입력·빠른 선택과 중복 기록 제거(M36), 검색바·설정 사이드바(M37), 세 콤보박스 단축키와 충돌 처리(M38~M39)를 실제 개발 앱에서 확인한다.
3. 1주 실사용으로 카드 밀도·창 유지·리모컨의 체감 개선을 평가한다.
4. M44~M45에서 빈 영역 드래그·위치 복원과 활성화 시 검색 포커스·모달 예외를 실제 개발 앱으로 확인한다.
5. 보안 후속인 민감 항목 미저장과 외부 내비게이션 차단을 검토한다.
6. 이미지 data URL 대용량 처리와 트레이 상주는 실사용 결과에 따라 결정한다.
