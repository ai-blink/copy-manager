# dev-brief — copy-manager

## 목표

Windows 11 파워유저가 클립보드 기록을 한눈에 더 많이 보고, 키보드·스크롤로 끊김 없이 탐색해 원하는 앱에 붙여넣도록 `win+v`를 보완·대체한다.

## 해결할 문제

- 좁은 `win+v` 창 때문에 기록을 훑으려면 반복해서 스크롤해야 한다.
- 화살표 탐색이나 좁은 스크롤바 조작 중 창이 닫혀 흐름이 끊긴다.
- 마우스 휠 없이 긴 히스토리를 탐색하기 어렵다.

## 사용자와 사용 맥락

- 사용자: 본인 한 명, Windows 11 개발자·파워유저, 한국어 UI
- 사용 맥락: 코딩·문서 작업 중 수시로 복사 기록을 검색·재사용
- 기본 흐름: `Ctrl+Alt+V` → 검색/키보드 탐색 → 클릭으로 복사 또는 `Enter`로 직전 앱에 붙여넣기

## 성공 기준

- 기본 3열에서 한 화면 9개 이상의 카드를 확인할 수 있다.
- 화살표·스크롤 탐색 중 의도치 않은 닫힘이 없다.
- 창 내부 리모컨만으로 히스토리 끝까지 이동할 수 있다.
- 1주 실사용 후 “win+v보다 덜 답답하다”고 판단한다.
