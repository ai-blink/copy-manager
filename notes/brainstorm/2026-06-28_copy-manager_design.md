## 1. 한 줄 목표 ⭐
**나(파워유저)가 클립보드 히스토리를 한눈에 더 많이 보고, 키보드·스크롤로 끊김 없이 탐색·붙여넣도록** win+v를 대체하는 데스크톱 클립보드 매니저를 만든다.

## 2. 문제 (지금 win+v가 막히는 곳)
- **좁아서 몇 개 안 보임** — 히스토리를 훑으려면 계속 스크롤해야 함
- **키보드로 못 내려감** — 화살표로 아래 리스트 보려다 **창이 닫힘**
- **스크롤이 위험** — 좁은 스크롤바를 잡고 내리다 살짝 빗나가면(포커스 밖 클릭) **창이 닫힘**
- 근거: 본인 일상 사용 경험(직접 관찰). 안 풀면 → 복사 자주 쓰는 작업마다 마찰·집중 끊김.
- ⚠ **막힘 1줄 = "보이는 개수가 적고, 탐색하다 창이 닫힌다"** → 8번 지표와 짝.

## 3. 사용자 & 맥락
- **누가**: 본인 (Windows 11 파워유저, 개발자). 단일 사용자 개인 도구.
- **언제·어디서**: 코딩·문서 작업 중 수시로, 손은 키보드·마우스에.
- **제약**: 한국어 UI, Windows 전용. 마우스 휠 없이도(리모컨) 탐색하고 싶음.

## 4. 사용자 여정 (이번에 고칠 막힘 집중)
| 단계 | 행동 | 생각·감정 | 막히는 점 | 개선 |
|---|---|---|---|---|
| 1 | 핫키로 클립보드 창 연다 | "최근 복사한 거 어딨지" | win+v는 좁아 일부만 | 큰 창 + 3열 그리드로 한 번에 多 |
| 2 | **화살표/스크롤로 항목 탐색** | "아래 거 보려는데…" | **창이 닫혀버림** ← 이번 핵심 | **키보드·스크롤로 절대 안 닫힘** + 핀 고정 |
| 3 | 항목 선택→Enter | "이거 붙여넣자" | — | 그대로 붙여넣기 |
+ 끝난 뒤: 작업하던 앱으로 자동 복귀(자동숨김) 또는 핀이면 그대로 떠 있음.

## 5. 핵심 흐름 (시작→완료)
1. **자체 전역 핫키**(예: win+y / Ctrl+Shift+V, 설정 변경 가능)로 창을 복원·표시·활성화
2. (선택) 검색창에 타이핑 → 카드 **즉시 필터** (B·검색우선)
3. `←→↑↓`로 카드 그리드 탐색 — **창 안 닫힘**
4. 필요 시 **스크롤 리모컨**(▲▼)으로 긴 히스토리 스크롤 (드웰 게이지 또는 클릭)
5. **카드 클릭 = 복사**("✓ 복사됨" 시각화) / **Enter·더블클릭 = 직전 앱에 붙여넣기** (구분)
6. (선택) 카드 `⋯` → **상세 보기 모달**(전체 내용) / `🗑️` → **"삭제할까요?" 확인** 후 삭제
7. 붙여넣기 시 창을 숨기고 직전 앱으로 복귀. 그 외에는 기본적으로 창 유지하며, 필요하면 **창 유지** 설정을 해제해 blur 시 자동숨김
- 역방향: `Esc`로 모달 닫기. 창을 다시 전면에 가져오려면 핫키를 다시 누른다.

## 6. 화면 / 출력 의도
**클립보드 창**
- 핵심 행동 1개: **원하는 항목 골라 붙여넣기**
- 1순위: 카드 그리드(균일 4:3, 최근 항목 多) · 2순위: 타입 탭(전체/텍스트/이미지/링크/코드)+검색창 · 3순위: 핀/설정/유지개수
- 카드 호버 액션 **📌 ⋯ 🗑️** + **우클릭 메뉴**(복사·평문붙여넣기·상세·핀·삭제) / **빈 상태**: "비어 있어요" · "조건에 맞는 항목 없음"
- **상세 보기 모달**(⋯): 전체 내용 + 복사/붙여넣기/핀/삭제 / **삭제는 확인 모달**(실수 방지)
- 헷갈릴 점: 클릭=복사 vs Enter=붙여넣기 구분 → 푸터에 명시 · "왜 안 닫히지?" → 자동숨김/핀 상태 푸터 표시

**설정 화면 (⚙️ 모달)**
- 전역 핫키 · 한 줄 카드 수 · 유지 개수 · 리모컨(투명도·드웰·속도·모드)
- ☑ **재부팅(앱 재시작) 시 기본값으로 리셋** · **[메모리 리셋]** 버튼(전체 기록 삭제, 확인)

**스크롤 리모컨 (창 내부 플로팅)**
- 핵심 행동 1개: **마우스 휠 없이 위/아래 스크롤**
- 1순위: ▲▼ 버튼 + 드웰 게이지(아래→위 차오름) · 2순위: ⚙ 설정 · 3순위: 창 안 자유 위치
- 평소 **반투명(설정값) → 호버 시 불투명**. **창 안에서만 드래그 이동**(4모서리·도킹 폐기)
- 헷갈릴 점: 드웰=호버 유지로 발동 → 게이지로 "곧 시작" 시각화로 해소

## 7. 우선순위 (안 함부터)
| 구분 | 내용 |
|---|---|
| **안 함** | ① **전역(시스템 전체) 스크롤 리모컨** → 이번엔 클립보드 창 전용. 전역판은 **별도 프로젝트**로 분리 (단, 떼어내기 쉽게 느슨 결합만) ② **클라우드 동기화** → 로컬만으로 충분 ③ **다국어** → 본인용 한국어 ④ **win+v 강제 가로채기** → 불안정, 자체 핫키로 대체 ⑤ **크로스플랫폼(mac/Linux)** → Windows 전용 |
| Must | 핫키로 창 복원·표시·활성화 · 클립보드 히스토리 캡처(50개) · 3열 카드 그리드(**4:3 균일**) · 키보드 탐색 안 닫힘 · 핀 토글 · 넓은 스크롤바 · 스크롤 리모컨(**창 내부 플로팅**·드웰/클릭·속도·▲▼⚙) |
| Should | 검색 필터 · **타입 탭(이미지 등)** · **클릭=복사 시각화** · **카드 ⋯ 상세 모달** · **삭제 확인 모달** · 우클릭 메뉴 · 빈 상태 · **리모컨 투명도(호버 불투명)** · 항목 핀(영구보존) · 설정 모달(핫키·열수·유지개수·드웰·속도·투명도·**재부팅 시 기본값 리셋**·**메모리 리셋**) · 이미지 항목 |
| Could | 항목 타입 필터 · 붙여넣기 시 평문 변환 · 파일 경로 항목 · 테마 |

## 8. 성공 지표 (2번 막힘과 짝)
- **보이는 개수**: win+v ~3개 → **한 화면 9개+**(3×3) — 직접 관측(세어보면 됨)
- **의도치 않은 닫힘**: 화살표·스크롤 조작 중 닫힘 **발생 → 0회** (핵심)
- **휠 없는 탐색**: 스크롤 리모컨만으로 히스토리 끝까지 이동 가능 = 됨/안됨
- 정성: "win+v보다 안 답답하다"를 본인이 1주 써보고 체감

## 9. 검증 계획
- **누가**: 본인 단독
- **언제**: 각 슬라이스 완료 직후 + 1주 실사용
- **어떻게**: 실제로 핫키로 열어 ①한 화면 카드 수 세기 ②화살표/스크롤 마구 눌러 안 닫히는지 ③리모컨만으로 끝까지 스크롤 — **실사용 직접 관측**(테스트 통과 아님)
- **안 좋아지면**:
  - Plan B(축소): 리모컨 도킹·드웰 빼고 클릭 스크롤 + 고정 위치만이라도
  - Plan C(되돌리기): 1주 써서 win+v보다 불편하면 win+v로 복귀(앱은 보조로)

## 부록 — 당시 기술 제안 / 구현 슬라이스

> 아래 내용은 구현 전 제안이므로 현재 사실 확인에는 사용하지 않는다. 현재 구조는 `rules/dev-arch.md`, 현재 일정은 `rules/dev-roadmap.md`를 따른다.

**스택**: Electron + TypeScript + Vite. 렌더러는 우선 vanilla TS(필요 시 경량 프레임워크). 저장은 로컬(JSON 또는 SQLite better-sqlite3).

**핵심 동작**
- 창: `BrowserWindow` frameless + `alwaysOnTop` + transparent. 기본 `keepOpen=true`에서는 blur를 무시하고, 설정을 해제했을 때만 `blur` 이벤트에 `hide()`.
- 전역 핫키: `globalShortcut.register` (기본값 설정에서 변경). win+v(OS 클립보드 기록)와 공존.
- 클립보드 캡처: 폴링(`clipboard.readText/readImage`) 또는 네이티브 후킹. 타입: 텍스트/링크/코드(텍스트)/이미지. ring buffer 50, **핀 항목은 카운트 제외·영구 보존**.
- 클릭=복사: 카드 클릭 시 `clipboard.write` + "복사됨" 플래시. 붙여넣기(Enter/더블클릭): `clipboard.write` 후 직전 포커스 앱에 `Ctrl+V` 합성(robotjs/nut.js 등) — 안정성 검토 대상.
- 설정 영속화: 설정값 로컬 저장. **☑ 재부팅 시 기본값 리셋** 체크 시 시작할 때 기본값 로드(저장값 무시). **[메모리 리셋]**=히스토리 스토어 전체 비우기(핀 포함, 확인 후).
- 상세 모달/삭제 확인/모두 지우기 확인: 비가역 동작은 확인 모달 경유(실수 방지).
- 그리드: `repeat(cols,1fr)` + `grid-auto-rows`를 카드폭×3/4로 JS 고정(**균일 4:3·겹침 방지**), 가상 스크롤, 스크롤바 14px. **타입 탭 필터 + 검색 필터** 조합.
- 스크롤 리모컨: 별도 컴포넌트(전역판 분리 대비 느슨 결합). 드웰=rAF로 0→100% 게이지 후 auto-repeat. 모드 드웰/클릭, 속도·**투명도** 설정. **창 내부 플로팅**(창 영역 내 자유 드래그, 평소 반투명→호버 불투명). 4모서리/도킹 개념 폐기.

**구현 슬라이스 순서 (작게 → 검증 가능 단위)**
1. Electron 셸: frameless/alwaysOnTop/transparent + 전역 핫키 창 복원·표시·활성화 + `keepOpen=false`일 때 blur→hide
2. 클립보드 캡처 + 50 ring buffer + 핀 영구보존 + 로컬 영속화
3. 카드 그리드 UI(B 검색우선, 3열 설정가능, 4:3) + 키보드 탐색(안 닫힘) + 붙여넣기
4. 스크롤 리모컨(플로팅·드웰 게이지·클릭·속도·▲▼⚙·4모서리·창 도킹)
5. 설정 화면(핫키·열 수·유지 개수·드웰 임계·속도·리모컨 위치)
