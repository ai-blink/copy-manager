# dev-brief — copy-manager

## 한 줄 목표
나(파워유저)가 클립보드 히스토리를 **한눈에 더 많이 보고, 키보드·스크롤로 끊김 없이 탐색·붙여넣도록** `win+v`를 대체하는 데스크톱 클립보드 매니저.

## 문제 (지금 win+v가 막히는 곳)
- 좁아서 몇 개 안 보임 (계속 스크롤해야 함)
- 화살표로 아래 항목 보려다 **창이 닫힘**
- 좁은 스크롤바 조작 중 살짝 빗나가면(포커스 밖 클릭) **창이 닫힘**
- → 핵심 막힘: **"보이는 개수가 적고, 탐색하다 창이 닫힌다"**

## 사용자 & 맥락
- 본인(개발자, Windows 11 파워유저). 단일 사용자 개인 도구. 한국어 UI.
- 코딩·문서 작업 중 수시 사용. 마우스 휠 없이도(스크롤 리모컨) 탐색 원함.

## 성공 지표 (막힘과 짝)
- 한 화면에 보이는 항목: win+v ~3개 → **9개+**(3×3 그리드)
- 화살표·스크롤 조작 중 의도치 않은 닫힘: **0회**
- 스크롤 리모컨만으로 히스토리 끝까지 이동 가능

## 범위 밖 (안 함)
전역 스크롤 리모컨(별도 프로젝트) · 클라우드 · 다국어 · win+v 가로채기 · 크로스플랫폼
