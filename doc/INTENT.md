# INTENT — copy-manager

Windows 11 `win+v`의 세 가지 불편(① 좁아 몇 개만 보임 ② 화살표 탐색 중 창 닫힘 ③ 스크롤 중 창 닫힘)을 없앤, **본인 전용** Electron+TypeScript 클립보드 매니저를 만든다.

핵심 가치: **더 많이 보이고(3×3 카드 그리드), 키보드·스크롤로 조작해도 안 닫히고(핀 토글), 마우스 휠 없이도 탐색(창 내부 스크롤 리모컨)**.

성공은 테스트 통과가 아니라 **본인이 1주 써서 "win+v보다 안 답답하다"를 체감**하는 것으로 판정한다.
